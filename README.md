# Chiba-kun map

Live: https://yohman.github.io/chibakun/

Standalone static site. Serve this directory with any HTTP server; no build or dependencies.

Hover or tap Chiba-kun to reveal the nearest city. City points also support keyboard focus and Enter. Drag to pan; scroll or use the small controls to zoom. The corner reset control and Escape restore Chiba. City points use geographic coordinates; character alignment is an illustrative approximation.

## Sources

- Japan prefecture boundaries: https://github.com/dataofjapan/land — simplified for display, including Chiba's darker dotted layer.
- Reference for the cleaned-up Chiba-kun artwork: Chiba Prefectural Government, design guide cover, https://www.pref.chiba.lg.jp/kouhou/miryoku/chi-ba-kun/documents/tibakundezaingaidomanyuaru20230801.pdf
- Character: 千葉県マスコットキャラクター「チーバくん」. Artwork remains the property of Chiba Prefecture. Public use is subject to the prefecture's design-use process: https://www.pref.chiba.lg.jp/kouhou/miryoku/chi-ba-kun/designsiyou.html

The map starts centered on Chiba. Zoom out to view the rest of Japan. All assets are served locally.

The character was cleaned up from the official reference. The border-free geographic dot layer sits above the transparent artwork; the Map–Chiba-kun slider fades the character without moving the geography. Registration uses an approximate 10-degree clockwise rotation to bring the nose, eastern ear and southern foot closer to their geographic counterparts.
